03 · The gap

Today’s security tools each see half the picture.

OT SECURITY

Sees the wire, not the AI

Dragos, Claroty and Nozomi decode Modbus and DNP3 traffic, but can’t tell which AI agent sent a command or why.

AI SECURITY

Sees the prompt, not the breaker

Prompt firewalls now owned by Palo Alto, Check Point and SentinelOne inspect model calls, but don’t know a tool call can open a breaker.

LOCKOUT

Sees both

We tie each AI action to its physical consequence and apply policy written in operators’ terms: read-only, approve-first, or never.

Lockout · Confidential

This is the wedge. OT security vendors are experts in industrial protocols; AI security vendors are experts in models. Nobody joins the two. Be generous about incumbents: they are potential partners and acquirers, not enemies.
